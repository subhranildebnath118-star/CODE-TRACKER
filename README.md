# Code Tracker

A full-stack web application that helps developers and students track their learning progress across programming roadmaps. Stay consistent with streak tracking, monitor topic-wise completion, and visualize your growth.

---

## Features

- **Roadmap-Based Learning** – Structured learning paths for different programming languages
- **Progress Tracking** – Mark topics as completed and track overall progress
- **Streak System** – Maintain daily learning consistency
- **User Authentication** – Secure signup and login system
- **Dynamic Dashboard** – Real-time progress updates and visual indicators
- **Multi-Language Support** – Track progress across Python, Java, C++, JavaScript, and more

---
