Code Tracker

A modern developer productivity web application designed to help you track your coding journey, stay consistent, and visualize your progress across multiple programming languages.

Overview

Code Tracker provides a structured roadmap-based learning system where users can:

Track completed topics 
Monitor progress visually 
Maintain daily learning streaks 
Switch between multiple programming languages 

Features:
Roadmap-Based Learning
Predefined structured paths (Beginner → Advanced)
Progress Tracking System
Save and retrieve completed topics
Real-Time Progress UI
Dynamic circular progress indicator
Streak System
Tracks daily consistency
Multi-Language Support
Python, Java, C++, JavaScript, etc.
Fast & Lightweight Backend
Built using Flask and SQLite
🛠️ Tech Stack
Layer	Technology
Frontend	HTML, CSS, JavaScript
Backend	Flask (Python)
Database	SQLite

Setup Instructions:
1. Clone the Repository
git clone https://github.com/subhranildebnath118-star/CODE-TRACKER.git
cd CODE-TRACKER
2. Install Dependencies
pip install flask flask-cors
3. Run the Application
python3 app.py
4. Open in Browser
http://127.0.0.1:5000
